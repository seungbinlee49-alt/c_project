런타임 설정 파일로 GPU나 FP32로 바뀌지 않으며, 모델 SHA256이 다르면 오류 112.

시간 해석
최신 과제 ver2 PDF에는 함수별 250ms, 인식 전체 5초 수치 상한이 없다.
5초는 사용자가 별도로 들은 내용과 팀 평가 프로그램에 맞춘 운영 검증 목표다.
앞선 동일 수치 알고리즘의 별도 시험에서는 최대 4.418초, 팀 프로그램 4.672초였다.
최종판이 수학적으로 더 빨라졌다는 의미는 아니며 PC 부하·전원·캐시 등에 따라 시간이 변할 수 있다.
시험 PC: Intel Core i5-13500HX, Windows x64, 단일 Worker.
새 프로세스의 모델 초기화는 포함하나 OS 파일 캐시는 따뜻할 수 있다.
다른 CPU나 모든 동시 실행 수, 모든 가능한 입력에서의 5초 보장은 아니다.

인식 성능: 3개 DB 평균 EER, 실패 포함, 소수점 셋째 자리 점수
원본: FP32 64개 0%, INT8 64개 0%.
가우시안 표준편차 30: FP32 64개 0.069444%, INT8 64개 0.446429%.
새 픽셀별 표준편차 0~45: FP32 64개 0%, INT8 64개 0%.
INT8의 개별 DB2 가우시안 EER은 1.339286%이며 정확도 손실이 있다.
양자화 범위는 외부 CrossMatch 예시로 보정했고 과제 DB나 비교 정답은 사용하지 않았다.
같은 손가락 영상의 새 잡음은 독립 손가락 일반화 시험이 아니다.
원본 신경망 학습 영상 전체와 시험 영상의 비중복을 모두 감사한 결과도 아니다.

최종판 변경에 대한 검증
수치 알고리즘·모델을 바꾸지 않고 모델 무결성 및 템플릿 형식을 강화했다.
새 형식으로 옮긴 기존 실제 INT8 템플릿 7,110쌍에서 이전 점수 및 EER 전부 동일.
최종판으로 실제 추출한 대표 18개 템플릿의 특징 본문도 이전 결과와 바이트 단위 동일.
부분 평가 4쌍: Worker 1개와 2개 결과 동일.
NOACCESS 입력 경계, 출력 canary, 잘못된 인자·템플릿·모델·부속 파일, 비표준 예외 검사 통과.
같은 원본에 대한 전체 750개 CNN 추출을 최종 형식 변경 후 전부 반복한 것은 아니다.
독립 소스 폴더에서 알고리즘과 FingerJet을 다시 빌드했고 3개 DB 대표 템플릿 바이트 동일.
