과제 PDF 기준 점검 - 알고리즘 모듈 범위

참조: 01. 프로젝트(202602SME3007)_ver2.pdf, 지문인식 시험·인증 안내서 26~29쪽 및 31쪽.
PDF에는 알고리즘 자체의 이진 합격선 대신 3개 DB 평균 EER에 의한 상대 평가가 명시되어 있다.
따라서 이 문서는 기술 규격과 실제 시험의 충족 여부이며 교수자의 최종 채점이나 K-NBTC 인증서가 아니다.

[충족] C/C++ 구현, Windows DLL
근거: 과제 2쪽
확인: C++17, 배포 시 Python·독립 추론 EXE 호출 없음

[구성·출처 정리 / 교수자 해석 여지] 공개 라이브러리 단위 기능 및 출처
근거: 과제 2쪽
확인: FingerJet 추출, ONNX Runtime 추론; 자체 전처리·템플릿·대응·관계 검증 C++. 단위 기능 범위 승인 자체를 보장하지 않음

[충족] KISA 함수 3개와 정확한 인자
근거: 과제 6쪽 / 안내서 26~29쪽
확인: extern C / cdecl / KISA_Enroll, KISA_Attempt, KISA_Compare만 공개

[충족] iType 1/2/3
근거: 과제 6쪽
확인: 1=448x478, 2=300x300, 3=640x480, 8-bit RAW, 500ppi

[충족] 템플릿 <1,000,000 bytes
근거: 안내서 26~28쪽
확인: 최대 213,800 bytes

[충족] double 점수 0~1, 최대 소수점 3자리
근거: 안내서 29쪽
확인: 범위 제한, round(value*1000)/1000, 7,110쌍 검증

[충족] 성공 1 / 실패 0, 오류 코드·256-byte 메시지
근거: 안내서 26~29쪽
확인: 실패 size=0 또는 score=0, 원인별 코드, 표준·비표준 예외 처리

[충족] DLL 자기 경로에서 부속 파일 로딩
근거: 안내서 31쪽
확인: FRFXLL·ONNX Runtime·모델을 자체 폴더에서 접근, CWD/PATH 독립 시험

[알고리즘 측 충족] 비교 순서에서 정답 유추 방지
근거: 과제 4쪽
확인: 입력은 타입·픽셀/템플릿뿐, 파일명·정답 라벨 접근 없음, 무작위 회귀 순서 점수 동일

[연결 시험 충족] 병렬 및 부분 평가
근거: 과제 4쪽
확인: 팀 CLI 부분 평가 4쌍, Worker 1/2 점수 동일. GUI 전체 검증을 대체하지 않음

[검증·재현 설정 충족] 실패 포함 EER, DB 3개 산술 평균
근거: 과제 7·8·12쪽
확인: FVC 방식, predefined 분모, EER*와 구분. PDF에 EER 1% 합격선 없음

[측정 자료 제공] 등록/정합 시간·템플릿 크기 리포트
근거: 과제 9쪽
확인: evidence에 시간·크기 포함. GUI 리포트 완성도는 팀 평가 소프트웨어 범위

[충족] 알고리즘 소스·DLL·구동 파일
근거: 과제 14쪽
확인: source, runtime/x64, 모델, 라이선스, 대응 소스 포함

[모듈 패키지 제공] 설치 및 배포
근거: 과제 2·13쪽
확인: 포터블 폴더 및 선택적 install/uninstall. 팀 GUI 설치 프로그램은 별도 범위

[이 PC에서 충족] 3함수 합계 <5초
근거: 별도 운영 목표
확인: 단일 Worker의 실제 측정. PDF상의 숫자 제한으로 오인하지 않음

[별도 팀 과제] 평가 GUI 전체 70점·발표 10점
근거: 과제 13·14쪽
확인: 전체 기능/리포트/벡터 그래프/객체지향/UI/PPT/역할 기여/시연은 DLL만으로 완료되지 않음

추가 배포 검증: 설치 파일 SHA256 검증, 설치 후 실제 인식, 제거 시 사용자 추가·수정 파일 보존을 확인했다.
